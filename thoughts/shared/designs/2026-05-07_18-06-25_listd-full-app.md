# Design: Listd - Native Flutter To Do App with Google Tasks Integration

## Summary

Build a native Flutter To Do application with Google Tasks integration for Linux desktop (with cross-platform support). Architecture uses Material 3 with Indigo (#5C6BC0), Riverpod for state management, drift for SQLite caching, go_router for navigation, and OAuth2 PKCE via the oauth2 Dart package for Google authentication. The ITaskProvider interface enables provider-agnostic design allowing future local-only or alternate cloud providers.

## Requirements

- Native Flutter app for Linux desktop (cross-platform: Android, iOS, macOS, Windows)
- Google Tasks integration (list, create, update, delete tasks and task lists)
- OAuth2 PKCE authentication with secure token storage
- Local SQLite caching via drift for offline read access
- Material 3 theming with light/dark mode support
- go_router for navigation with auth-aware redirects

## Current State Analysis

The project is at the default Flutter template stage with only `lib/main.dart` containing the counter app. No implementation exists. The research artifact defines the target architecture.

## Scope

### Building

- Complete Flutter application with all layers:
  - Theme and core types
  - Drift database with tables and DAOs
  - OAuth2 PKCE authentication flow
  - Google Tasks API integration
  - Task sync service
  - Riverpod providers for state management

### Not Building

- Offline editing (read-only cached mode per discover spec)
- Infinite scroll pagination (fetch all tasks)
- Advanced conflict resolution (last-write-wins only)
- Testing infrastructure (deferred to implementation phase)

## Decisions

### Offline Mode

**From Open Question**: What is the offline strategy for v1?

- **Decision**: Read-only cached mode
- **Evidence**: Per discover spec, v1 provides read-only cached mode for offline access
- **Implementation**: Local drift database caches all synced data; writes require network

### Token Refresh

**From Open Question**: Should token refresh failures show a UI error or silently trigger re-auth?

- **Decision**: Silent refresh with error fallback
- **Evidence**: Common OAuth pattern - attempt refresh silently, only show error if refresh fails
- **Implementation**: TokenManager checks expires_at, auto-refreshes using refresh_token; on failure, throws exception for UI to handle

### Pagination

**From Open Question**: Should the app fetch all tasks or implement pagination with infinite scroll?

- **Decision**: Fetch all tasks
- **Evidence**: Simpler implementation, works for typical task list sizes
- **Implementation**: GoogleTasksProvider fetches all tasks in single API call per task list

### Auth Library

**From Developer Context**: Which OAuth2 package to use?

- **Decision**: oauth2 Dart package (pure Dart, not google_sign_in or AppAuth)
- **Evidence**: Research artifact Developer Context Q/A selected "oauth2 package (Recommended)"
- **Implementation**: Custom PKCE implementation with oauth2 package

### Architecture Pattern

**Simple Decision**: Use layered architecture as documented in research

- **Pattern**: Screens → Providers → Services → Data + External APIs
- **Evidence**: `lib/main.dart:1` — Entry point with ProviderScope, `lib/providers/task_lists_provider.dart` — State providers
- **Implementation**: Follow documented architecture in research

/// Sync status for local database records
enum SyncStatus {
  /// Record is synced with remote
  synced,

  /// Record was created locally and needs to be pushed to remote
  createdLocally,

  /// Record was updated locally and needs to be pushed to remote
  updatedLocally,

  /// Record was deleted locally and needs to be deleted from remote
  deletedLocally,
}

/// Extension to convert SyncStatus to/from integer for database storage
extension SyncStatusExtension on SyncStatus {
  /// Convert enum to integer for database storage
  int get value {
    switch (this) {
      case SyncStatus.synced:
        return 0;
      case SyncStatus.createdLocally:
        return 1;
      case SyncStatus.updatedLocally:
        return 2;
      case SyncStatus.deletedLocally:
        return 3;
    }
  }

  /// Create enum from integer from database
  static SyncStatus fromValue(int value) {
    switch (value) {
      case 0:
        return SyncStatus.synced;
      case 1:
        return SyncStatus.createdLocally;
      case 2:
        return SyncStatus.updatedLocally;
      case 3:
        return SyncStatus.deletedLocally;
      default:
        return SyncStatus.synced;
    }
  }
}

  DateTimeColumn get updated => dateTime()();

  TextColumn get parentId => text().nullable()();

  IntColumn get position => integer().withDefault(const Constant(0))();

  }

  /// Watch tasks for a specific task list
  Stream<List<Task>> watchTasksByListId(String taskListId) {
    final query = select(tasksTable)

    return query.watch().map((rows) => rows.map(_mapToDomain).toList());
  }

  /// Get all tasks for a specific task list (non-stream)
  Future<List<Task>> getTasksByListId(String taskListId) {
    final query = select(tasksTable)
      ..where((t) => t.taskListId.equals(taskListId) & t.syncStatus.isNotIn([3]));
    return query.get().then((rows) => rows.map(_mapToDomain).toList());
  }

  /// Get all tasks (non-stream)
  Future<List<Task>> getAllTasks() {
    final query = select(tasksTable)
      ..where((t) => t.syncStatus.isNotIn([3]));
    return query.get().then((rows) => rows.map(_mapToDomain).toList());
  }

  /// Get task by ID and taskListId
  Future<Task?> getTask(String taskListId, String taskId) {
    final query = select(tasksTable)
      ..where((t) => t.taskListId.equals(taskListId) & t.id.equals(taskId));
    return query.getSingleOrNull().then((row) => row != null ? _mapToDomain(row) : null);
  }

  /// Insert or update a task (upsert)
  Future<void> upsertTask(Task task) async {
    await into(tasksTable).insertOnConflictUpdate(
      TasksTableCompanion(
        id: Value(task.id),
        title: Value(task.title),
        notes: Value(task.notes),
        due: Value(task.due),
        isCompleted: Value(task.status == TaskStatus.completed),
        updated: Value(task.updated),
        taskListId: Value(task.taskListId),
        parentId: Value(task.parentId),
        position: Value(task.position),
        syncStatus: Value(task.syncStatus.value),
      ),
    );
  }

  /// Insert or update multiple tasks (batch)
  Future<void> upsertTasks(List<Task> tasks) async {
    await batch((batch) {
      for (final task in tasks) {
        batch.insert(
          tasksTable,
          TasksTableCompanion(
            id: Value(task.id),
            title: Value(task.title),
            notes: Value(task.notes),
            due: Value(task.due),
            isCompleted: Value(task.status == TaskStatus.completed),
            updated: Value(task.updated),
            taskListId: Value(task.taskListId),
            parentId: Value(task.parentId),
            position: Value(task.position),
            syncStatus: Value(task.syncStatus.value),
          ),
          onConflict: DoUpdate((_) {
            return TasksTableCompanion(
              title: Value(task.title),
              notes: Value(task.notes),
              due: Value(task.due),
              isCompleted: Value(task.status == TaskStatus.completed),
              updated: Value(task.updated),
              parentId: Value(task.parentId),
              position: Value(task.position),
              syncStatus: Value(task.syncStatus.value),
            );
          }),
        );
      }
    });
  }

  /// Delete a task by marking as deleted locally (for sync)
  Future<void> markDeletedLocally(String taskListId, String taskId) async {
    await (update(tasksTable)
          ..where((t) => t.taskListId.equals(taskListId) & t.id.equals(taskId)))
        .write(const TasksTableCompanion(syncStatus: Value(3)));
  }

  /// Permanently delete a task
  Future<void> deleteTask(String taskListId, String taskId) async {
    await (delete(tasksTable)
          ..where((t) => t.taskListId.equals(taskListId) & t.id.equals(taskId)))

  }

  }

  /// Mark tasks as synced after successful sync
  Future<void> markSynced(List<String> taskIds, String taskListId) async {
    await (update(tasksTable)
          ..where((t) => t.id.isIn(taskIds) & t.taskListId.equals(taskListId)))
        .write(const TasksTableCompanion(syncStatus: Value(0)));
  }

  /// Map database row to domain model
  Task _mapToDomain(TasksTableData row) {
    return Task(
      id: row.id,
      title: row.title,
      notes: row.notes,
      due: row.due,
      status: row.isCompleted ? TaskStatus.completed : TaskStatus.needsAction,
      updated: row.updated,
      taskListId: row.taskListId,
      parentId: row.parentId,
      position: row.position,
      syncStatus: SyncStatusExtension.fromValue(row.syncStatus),
    );
  }
}

        'code_verifier': _codeVerifier,

        'redirect_uri': _redirectUri,

      throw AuthException('Token exchange failed: ${response.body}');

    final tokens = jsonDecode(response.body) as Map<String, dynamic>;
    final accessToken = tokens['access_token'] as String;
    final refreshToken = tokens['refresh_token'] as String?;
    final expiresIn = tokens['expires_in'] as int;

    // Store tokens
    await _storage.setAccessToken(accessToken);
    if (refreshToken != null) {
      await _storage.setRefreshToken(refreshToken);
    }
    final expiresAt = DateTime.now().add(Duration(seconds: expiresIn));
    await _storage.setTokenExpiresAt(expiresAt);

      refreshToken: refreshToken,
      expiresAt: expiresAt,

      'refresh_token': refreshToken, // Refresh token usually stays the same
      'expires_at': expiresAt,

class TokenManager {
  final SecureStorageService _storage;
  final GoogleAuthService _authService;

  TokenManager(this._storage, this._authService);

  /// Get a valid access token, refreshing if needed
  /// Returns null if not authenticated or refresh fails
  Future<String?> getValidAccessToken() async {
    final accessToken = await _storage.getAccessToken();
    if (accessToken == null || accessToken.isEmpty) {
      return null;
    }

    // Check if token needs refresh (expires within 5 minutes)
    final expiresAt = await _storage.getTokenExpiresAt();
    if (expiresAt != null) {
      final now = DateTime.now();
      if (expiresAt.difference(now).inMinutes < 5) {
        // Token expiring soon, try to refresh
        final refreshed = await _refreshToken();
        if (!refreshed) {
          // Refresh failed, return current token (caller should handle error)
          return accessToken;
        }
        // Token refreshed, get new token
        return _storage.getAccessToken();
      }
    }

    return accessToken;
  }

  /// Attempt to refresh the access token using refresh token
  /// Returns true if refresh successful
  Future<bool> _refreshToken() async {
    final refreshToken = await _storage.getRefreshToken();
    if (refreshToken == null || refreshToken.isEmpty) {
      return false;
    }

    try {
      final newTokens = await _authService.refreshAccessToken(refreshToken);
      if (newTokens != null) {
        await _storage.setAccessToken(newTokens['access_token']!);
        await _storage.setRefreshToken(newTokens['refresh_token']!);
        await _storage.setTokenExpiresAt(newTokens['expires_at']!);
        return true;
      }
    } catch (e) {
      // Refresh failed, tokens may be revoked
      await _storage.clearAll();
    }
    return false;
  }

    final accessToken = await _storage.getAccessToken();

  }

  /// Sync tasks for a specific task list
  Future<void> syncTasks(String taskListId) async {
    // Pull remote tasks
    await _pullTasks(taskListId);

    // Push local changes
    await _pushTasks(taskListId);
  }

  /// Pull tasks from remote for a task list
  Future<void> _pullTasks(String taskListId) async {
    try {
      final remoteTasks = await _taskProvider.getTasks(taskListId);
      await _database.taskDao.upsertTasks(remoteTasks);
    } catch (e) {
      // Log error but don't fail - offline mode
      // ignore: avoid_print
      print('Failed to pull tasks for $taskListId: $e');
    }
  }

  /// Push local task changes to remote for a task list
  Future<void> _pushTasks(String taskListId) async {
    final pendingTasks = await _database.taskDao.getPendingSyncTasks();
    final tasksForList = pendingTasks.where((t) => t.taskListId == taskListId).toList();

    for (final task in tasksForList) {
      try {
        switch (task.syncStatus) {
          case SyncStatus.createdLocally:
            final created = await _taskProvider.createTask(taskListId, task);
            await _database.taskDao.upsertTask(created.copyWith(syncStatus: SyncStatus.synced));
            break;

          case SyncStatus.updatedLocally:
            final updated = await _taskProvider.updateTask(taskListId, task);
            await _database.taskDao.upsertTask(updated.copyWith(syncStatus: SyncStatus.synced));
            break;

          case SyncStatus.deletedLocally:
            await _taskProvider.deleteTask(taskListId, task.id);
            await _database.taskDao.deleteTask(taskListId, task.id);
            break;

          case SyncStatus.synced:
            // Already synced, no action needed
            break;
        }
      } catch (e) {
        // Log error but continue with other tasks
        // ignore: avoid_print
        print('Failed to push task ${task.id}: $e');
      }
    }
  }

  /// Full sync - all task lists and all tasks
  Future<void> fullSync() async {
    await syncAll();

    // Get all task lists and sync their tasks
    final taskLists = await _database.taskListDao.getAllTaskLists();
    for (final taskList in taskLists) {
      await syncTasks(taskList.id);
    }
  }

  /// Provider for TaskSyncService
  static final provider = Provider<TaskSyncService>((ref) {
    final database = ref.watch(databaseProvider);
    final taskProvider = ref.watch(GoogleTasksProvider.provider);
    return TaskSyncService(database, taskProvider);
  });
}

## Ordering Constraints

1. **Slice 1 (Foundation)** must be first - other slices depend on types and theme
2. **Slice 2 (Data Layer)** depends on Slice 1 - needs tables defined first
3. **Slice 3 (Auth)** depends on Slice 1 - needs models for token storage
4. **Slice 4 (External API)** depends on Slice 3 - needs auth for API calls
5. **Slice 5 (Sync)** depends on Slices 2 and 4 - needs database and API
6. **Slice 6 (State)** depends on Slices 3, 4, 5 - needs all services wired
7. **Slice 7 (Navigation)** depends on Slice 6 - needs providers for auth redirect
8. **Slice 8 (UI)** depends on Slices 1, 6, 7 - needs theme, providers, router

Slices 1-4 can be generated in parallel (no cross-slice dependencies).
Slices 5-8 must be sequential after Slices 1-4.

## Developer Context

**Q (Discover): What is the Recommended Approach?**
A: Material 3 app with Riverpod state management, drift for local SQLite caching, go_router for navigation. ITaskProvider interface with GoogleTasksProvider implementation. OAuth2 PKCE via oauth2 Dart package (pure Dart, not google_sign_in or AppAuth), tokens in flutter_secure_storage, client ID from .env via flutter_dotenv. Desktop uses localhost redirect (127.0.0.1), Android uses custom URI scheme (listd://).

**Q (oauth2 package): The research assumes OAuth2 via oauth2 Dart package (not google_sign_in). Is this still the correct approach for your PKCE implementation?**
A: oauth2 package (Recommended)

**Q (Architecture choices): Offline mode, token refresh, pagination**
A: All defaults (Recommended) - Offline: read-only cache | Token refresh: silent with error fallback | Pagination: fetch all tasks

**Q (Slices): How should the application be decomposed?**
A: 8 slices (Recommended) - Slice 1: Foundation, Slice 2: Data Layer, Slice 3: Auth, Slice 4: External API, Slice 5: Sync, Slice 6: State, Slice 7: Navigation, Slice 8: UI
